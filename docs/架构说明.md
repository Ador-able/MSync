# 架构说明

## 职责

| 位置 | 职责 |
| --- | --- |
| `src` | TypeScript 界面、状态显示和用户选择 |
| `crates/desktop` | Tauri 命令、托盘、自动检查及任务调度 |
| `crates/core` | 端点、ADB、扫描、同步规划、执行和 SQLite 持久化 |
| `crates/logging` | 桌面程序与启动器共用的日志、限额和清理 |
| `crates/launcher` | 校验绿色包、准备离线运行缓存并启动桌面程序 |
| `tools` | 开发启动、集成验证、说明生成和打包 |

设备选择、ADB 子进程、协议解析和传输集中在 `core/src/adb.rs`。离线运行缓存与同步数据分属启动器和同步核心，界面不持有同步历史。

## 同步调用链

手动同步、自动检查和用户选版共用桌面任务入口，互斥执行，避免重叠写入。

1. `Coordinator.prepare` 读取绑定和忽略规则，创建缺失目录，判断是否需要合并，并行扫描两端内容摘要。
2. `plan::build` 根据当前快照和历史生成逐路径复制或删除操作；无法判断的版本进入冲突列表。
3. `Coordinator.execute` 备份旧版、暂存并核验新内容、替换目标，再通过 `Store.checkpoint_path` 保存该路径进度。
4. 全部文件和冲突完成后，更新身份记录、完整基线和成功时间；未完成路径继续保留历史。

冲突只阻塞对应路径。关闭选版窗口后后台仍继续检查，同一组未处理冲突不会反复弹出；内容变化后重新提示。修改忽略规则会废弃原待选快照，下次重新扫描。

## 状态与数据

`%LOCALAPPDATA%\MSync` 是默认本机状态目录：

| 位置 | 内容 |
| --- | --- |
| `state-adb.sqlite3` | 绑定、忽略规则、完整基线、逐文件进度和失败原因 |
| `logs` | 运行日志 |
| `runtime` | 启动器校验后的离线运行缓存 |
| `webview` | WebView2 用户数据 |

同步目录中的 `.usbsync-meta/endpoint.json` 记录端点身份，`_同步备份` 保留被覆盖或删除的旧文件。完整基线记录整轮结果，逐文件进度记录尚未合入基线的成功操作。

配置路径就是同步位置，不追踪被移走目录的新位置。卷或身份记录变化时按双方现有文件合并，暂不传播历史删除；整轮合并成功后才更新身份记录。合并可能补回此前仅在一侧删除的文件。

## 失败处理与代价

单路径失败按 1 秒、2 秒间隔重试，最多尝试 3 次，失败后继续其他路径。扫描失败的路径及子路径退出删除判断；整份扫描、设备或存储不可用时等待下一轮。取消保留已核验进度，部分完成不更新成功时间。

ADB 普通查询超时 30 秒，完整扫描及单次传输超时 30 分钟。子进程支持取消，目录锁防止重复写入；内容核验和备份在覆盖或删除前完成。MSync 与外部编辑器没有共同事务锁，同时替换同一文件无法获得跨程序原子保证。

每轮完整读取内容摘要，传输串行执行。备份不自动清理；冲突预览为独立校验副本，保留至正常退出，外部程序占用可能阻止清理。旧访问标记和备份归属标记只在固定位置清理，失败记日志并在下轮继续，不清理工作文件、实际备份或正式身份记录。
