# 使用说明

## 首次连接

1. 用 7-Zip 完整解压程序包，保留整个文件夹，运行 `MSync.exe`。
2. 在平板设置中开启开发者选项和 USB 调试，用可传输数据的数据线连接电脑并解锁平板。
3. 平板出现 USB 调试授权时，确认是自己的电脑后点“允许”。
4. 在 MSync 中选择电脑和平板的工作目录，先用少量文件确认目录，再开始同步。

开发者选项的入口依设备系统而异。电脑无法识别时，先更换插口或数据线，再安装设备厂商的 ADB 驱动。随包“首次连接”工具仅适用于它能识别的硬件接口，不能代替所有设备的厂商驱动。

## 日常同步

自动同步默认开启，程序空闲时约每分钟检查一次。可以继续编辑文件，正在保存或被占用的文件会稍后重试。准备拔线时，等待本轮显示“已完成”。关闭窗口会收起到托盘；完全退出请使用托盘菜单。

检查阶段显示进度动画和已用时间；传输阶段显示已处理项数、百分比和本轮用时。进度按文件与目录操作计数，失败项计入已处理数量，并在失败列表保留原因；百分比不表示字节进度或剩余时间。

绑定和同步进度保存在 `%LOCALAPPDATA%\MSync`。升级时先退出程序，完整解压新版，再启动即可。

如果还使用 FolderSync 等软件连接其他电脑，请先等上一段同步完成，再开始下一段同步。

## 同步规则

- 相同内容跳过；新增文件和单边修改传到另一端。
- 正常同步时，两边都修改则优先采用可明确判断的较新版；无法判断时提示选版。
- 一边删除且另一边没有修改时，另一边的文件移入 `_同步备份`，无需再次确认。
- 配置的目录被移动或删除后，在原位置重建并从另一端合并。磁盘或身份记录变化时，也先合并现有文件，暂不采用历史删除记录。
- 合并时保留双方独有文件，同名不同内容由用户选版。全部完成后恢复正常同步；此前仅在一侧删除的文件可能被补回。

程序不搜索被移走目录的新位置；尚未同步的内容仍留在移走的目录中。备份不自动清理，请预留空间。

选版窗口左右显示电脑和平板的版本。“打开”会用默认应用打开经过内容校验的临时副本，编辑副本不会修改源文件；平板版需先下载。不确定时选“稍后处理”或按 Esc，其他文件照常同步；首页“处理冲突”可再次打开。

## 忽略文件

在“更多设置 → 忽略文件”中，每行填写一条正则表达式，匹配所有子文件夹内的文件名。默认只有 `^~\$`，忽略 `~$` 开头的文件；留空则不忽略。

默认区分大小写，表达式前加 `(?i)` 可忽略大小写，例如 `(?i)\.tmp$`。语法错误会提示行号且不保存；规则采用 Rust regex 语法，不支持环视和反向引用。

保存后下次同步生效。忽略项不会读取内容、传输或删除，两端原有文件保留；目录名不受文件规则影响，移除规则后文件重新参与同步。

## 故障与恢复

单文件最多尝试 3 次，间隔 1 秒和 2 秒；仍失败则记录原因并继续其他文件。名称不受 Windows 支持或发生大小写冲突时，只暂缓对应路径。重启后继续检查未完成部分。

设备离线、未授权、存储不可访问或整份扫描失败时等待重试，不把读取失败当成空目录。手动“停止同步”会在本次运行期间暂停自动检查，点击“立即同步”继续。部分失败或仍有冲突时，不更新“上次成功”。

覆盖或删除前会备份并校验。找回旧文件请先停止同步，再点“打开备份”。程序与其他软件没有共同事务锁，无法保证同时替换同一文件时的原子协调。

点击“查看日志”可以查看或复制诊断信息。日志可能包含文件路径和设备标识，公开分享前请检查。单文件最多 10 MB，总量最多 100 MB，保留最近 7 天，超限时较旧日志会提前删除；日志写入失败不阻断同步。

冲突预览副本占用本机空间，正常退出时清理；外部程序占用或强制结束进程可能留下临时文件。旧辅助标记的清理失败只记日志，后续同步继续尝试，不影响工作文件和实际备份。
