## 验证边界

离线设备验证使用隔离文件、真实 SQLite、子进程及 Git Bash；界面验证使用真实 Tauri 页面和后端，设备与系统选目录对话框由测试提供。模拟结果不能代替真机验收。

本轮未在目标平板或干净的离线 Windows 电脑上验收，未重拍真机截图或重新生成完整绿色包。真机速度、设备端命令兼容性、首次驱动安装、物理拔线、锁屏重连、磁盘耗尽，以及 FolderSync 的完整链路仍需实测。

曾有环境出现 ADB 无法创建电脑端临时文件的下载失败；本机未复现。释放下载暂存文件句柄和默认忽略临时文档已有本地验证，但原故障是否解决仍需目标环境确认。

每轮完整内容扫描和串行传输有读写成本，备份及预览副本占用空间；跨程序同时替换文件没有共同事务锁。这些限制见 [使用说明](使用说明.md) 与 [架构说明](架构说明.md)。

命令与复现步骤见 [开发说明](开发说明.md)。测试证据保存在本机 `target` 中，不包含在源码仓库。
