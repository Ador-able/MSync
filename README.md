# MSync

通过 USB 在 Windows 电脑与 Android 平板之间双向同步文件，无需联网。使用 Rust、Tauri 和 TypeScript 构建。

## 使用

完整解压程序包，运行 `MSync.exe`，选择电脑和平板的工作目录后开始同步。平板需开启 USB 调试并授权电脑。关闭窗口会收起到托盘，通过托盘菜单完全退出。

- 新增和单边修改同步到另一端，相同内容跳过。
- 单边删除会传播到另一端；覆盖和删除前，旧文件保存到 `_同步备份`。
- 双方修改且无法判断版本时，保留双方内容并提示选版，其他文件继续同步。
- 自动同步开启时，空闲约每分钟检查一次；局部失败自动重试，成功进度逐文件保存。

首次使用建议先用少量文件确认目录。完整规则、忽略设置及故障处理见 [使用说明](docs/使用说明.md)。

## 开发

需要 Windows、Rust stable MSVC、Windows SDK/C++ 构建工具、Node.js 22.12 及以上版本，以及官方 Android Platform-Tools。将 Platform-Tools 解压到 `runtime/adb-download/platform-tools` 后运行：

```powershell
npm ci
npm run desktop
```

构建、验证、真机测试与离线打包步骤见 [开发说明](docs/开发说明.md)，模块职责和数据流见 [架构说明](docs/架构说明.md)。

## 限制

每轮完整读取文件内容摘要，传输逐个执行；大目录扫描有读写成本。备份不会自动清理。其他程序同时替换同一文件时，可能需要人工处理。

验证范围见 [验证记录](docs/验证记录.md)。
